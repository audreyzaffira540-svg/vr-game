One-Page Game Summary

1. Game Overview

Game Name: Cyber Lab: Advanced Escape

Theme: High-Tech Cyberpunk Security Facility

Player Objective: Collect the keycard, open the equipment locker, retrieve the UV flashlight, scan the wall for hidden ultraviolet codes, and input the code into the security terminal to escape.

Main Puzzles:
• Puzzle 1 (Access Control): Use the Keycard to unlock the Storage Locker.
• Puzzle 2 (Ultraviolet Scanning): Use the UV Flashlight on the north lab wall to reveal encrypted code digits (8-4-2).
• Puzzle 3 (Terminal Input): Enter the correct code sequence into the wall keypad to trigger the sliding exit doors.

2. Programming Techniques

• Game State Tracking: Multiple boolean and counter variables (hasKeycard, lockerOpen, hasFlashlight, uvActive, enteredCode) manage player progression across dependent stages.

• Event Listeners & DOM API: Uses A-Frame click/mouseenter listeners combined with Web Audio API sound synthesis for responsive feedback.

• Conditional Logic: Nested `if / else if` statements validate player inventory before allowing interactions like opening lockers or entering passcodes.

3. User Experience (UX) Decisions

Visual Feedback: Interactive objects scale up on hover (`mouseenter`), change color on activation, and update real-time status items in the HUD.

4. Evaluation

What Worked Well: The multi-tiered puzzle chain ensures the player interacts with multiple objects across the 3D environment.

Future Improvement: Adding movable physics objects or laser mirrors.
