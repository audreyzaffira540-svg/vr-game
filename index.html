One-Page Game Summary

1. Game Overview

Game Name: Cyber Lab: Escape Strategy

Theme: Futuristic Cyberpunk Research Facility

Player Objective: Re-activate the room's auxiliary generator and bypass security terminal locks to open the escape door.

Main Puzzles:
• Puzzle 1 (Power Connection): Retrieve the misplaced Plasma Core and slot it into the Power Pedestal.
• Puzzle 2 (Code Entry): Read the glowing encrypted passcode on the lab monitor wall (3-7-9) and enter it into the interactive wall terminal keypad.

2. Programming Techniques

• Game State Management: Utilised global state variables (e.g., hasCore, isPowered, enteredCode) to strictly track player progression.

• Event-Driven Interactions: Applied A-Frame click, mouseenter, and mouseleave event listeners to handle user gaze/click interaction inside 3D space.

• Conditional Logic & Functions: Created helper validation functions like checkCode() using if / else conditions to verify keypad inputs and trigger door animations.

Code Example:

function handleKeyInput(num) {
  if (!gameState.isPowered) {
    updateHUD("Power Pedestal must be activated first!");
    return;
  }
  gameState.enteredCode += num;
  if (gameState.enteredCode.length === 3) {
    if (gameState.enteredCode === gameState.targetCode) {
      unlockDoor();
    } else {
      resetKeypad();
    }
  }
}

3. User Experience (UX) Decisions

Visual & Audio Feedback: Dynamic hover effects (glowing/scaling elements when aimed at) and instant text updates on the HUD provide real-time guidance to eliminate player confusion.

4. Evaluation

What Worked Well: The seamless progression flow from item collection to power activation and final passcode entry.

Future Improvement: Adding a timed countdown alarm with flashing red alert lights to increase player tension.
